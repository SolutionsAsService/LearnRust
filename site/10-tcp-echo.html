A TCP echo server

What you'll build

A server that echoes back whatever each connected client sends, and a test that connects to it.

Run it

Run these from the course/ folder of the repository. First time? Install Rust and get the course (about ten minutes).

cargo run -p lesson-10-tcp-echo
# in another terminal:
nc 127.0.0.1 7878
cargo test -p lesson-10-tcp-echo

How it works

  • TcpListener::bind claims a port; incoming() yields a TcpStream per client.
  • read returning 0 bytes means the client hung up; the loop must stop there.
  • write_all keeps writing until every byte is sent (plain write may send only part).
  • Errors are returned as io::Result and logged per client, so one bad client can't crash the server.
  • The test binds to port 0, so the operating system picks a free port.

Where this came from

The original Cyber/TCPServer/Main.rs looped forever when a client disconnected (it kept echoing zero bytes), used write instead of write_all, and unwrapped every result. All three are fixed here.

//! Lesson 10: a TCP echo server, one thread per client.
//! Grown from the repository's original `Cyber/TCPServer/Main.rs`.

use std::io::{self, Read, Write};
use std::net::{TcpListener, TcpStream};
use std::thread;

/// Echo everything a client sends until it hangs up.
fn handle_client(mut stream: TcpStream) -> io::Result<()> {
    let peer = stream.peer_addr()?;
    let mut buffer = [0u8; 1024];
    loop {
        let n = stream.read(&mut buffer)?;
        if n == 0 {
            println!("{peer} disconnected");
            return Ok(()); // 0 bytes means the client closed the connection
        }
        stream.write_all(&buffer[..n])?;
        println!("{peer}: echoed {n} bytes");
    }
}

/// Accept clients forever, each on its own thread.
fn serve(listener: TcpListener) {
    for stream in listener.incoming() {
        match stream {
            Ok(stream) => {
                thread::spawn(move || {
                    if let Err(e) = handle_client(stream) {
                        eprintln!("client error: {e}");
                    }
                });
            }
            Err(e) => eprintln!("accept failed: {e}"),
        }
    }
}

fn main() -> io::Result<()> {
    let listener = TcpListener::bind("127.0.0.1:7878")?;
    println!("echo server on {}  (try: nc 127.0.0.1 7878)", listener.local_addr()?);
    serve(listener);
    Ok(())
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn echoes_what_it_receives() {
        // Port 0 asks the OS for any free port, so tests never collide.
        let listener = TcpListener::bind("127.0.0.1:0").unwrap();
        let addr = listener.local_addr().unwrap();
        thread::spawn(move || serve(listener));

        let mut client = TcpStream::connect(addr).unwrap();
        client.write_all(b"hello rust").unwrap();
        let mut reply = [0u8; 10];
        client.read_exact(&mut reply).unwrap();
        assert_eq!(&reply, b"hello rust");
    }
}

What it prints

This one is a server: it runs until you stop it, so there is no fixed output. Its test connects to it and checks the echo.
