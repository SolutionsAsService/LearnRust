The course

13 lessons, three tracks.

Each lesson is a small program you can run, read and break, with tests that pass on rustc 1.99.1. Do them in order, or jump to the track you need.

Foundations

The language itself: ownership, types, errors, traits, iterators and tests.

8 lessons · 24 tests

  1. 01 Hello, CargoCreate, run and test a Rust program with Cargo, Rust's build tool and package manager. 1 tests · 25 lines
  2. 02 Ownership, moves and borrowsEvery value has one owner. Learn when a value moves, when it is borrowed, and what the compiler says when you get it wrong. 3 tests · 56 lines
  3. 03 Structs, enums and matchModel data with structs and enums, attach behaviour with impl, and let match prove you handled every case. 3 tests · 78 lines
  4. 04 Collections: a bookstore inventoryKeep records in a HashMap, return a Result instead of panicking, and keep the logic testable apart from input and output. 3 tests · 117 lines
  5. 05 Error handling with ResultParse a config file where every failure is a typed value with a line number, not a crash. 3 tests · 85 lines
  6. 06 Traits and genericsShare behaviour across types with traits, write one function for many types with generics, and mix types with trait objects. 2 tests · 80 lines
  7. 07 Iterators and closuresChain filter, map and fold into a small log analyser, and write closures that capture their surroundings. 3 tests · 72 lines
  8. 08 Modules and testingSplit code into modules and a library crate, control visibility, and test it three ways: unit, doc and integration tests. 6 tests · 75 lines

Systems

Programs that share work across threads and talk over the network.

2 lessons · 3 tests

  1. 09 Fearless concurrencySplit work across threads, pass results over channels, and share a map safely with Arc and Mutex. 2 tests · 68 lines
  2. 10 A TCP echo serverListen on a socket, serve each client on its own thread, handle disconnects and errors, and test it end to end. 1 tests · 63 lines

Cryptography

Hashes, signatures and a blockchain you can break on purpose.

3 lessons · 8 tests

  1. 11 Hashing with SHA-256Use your first crate, hash text and files, check against a published test vector, and see the avalanche effect. 2 tests · 52 lines
  2. 12 Digital signaturesGenerate an Ed25519 key pair, sign a message, and prove that any change to the message, or the wrong key, fails verification. 3 tests · 57 lines
  3. 13 A toy blockchainChain blocks by hash, mine them with proof of work, and write the validator that catches tampering. 3 tests · 121 lines
